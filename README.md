# DOPAMINE

> Психологиялық мониторинг және эмоционалдық ахуалды қолдау платформасы.

Платформа ұжымдардың, студенттер мен оқушылардың орташа көңіл-күйін, эмоционалдық тұрақтылығын және психологиялық қолдау қажеттіліктерін қадағалауға арналған.

---

## 🛡️ Құпиялылық және этикалық саясат

- **100% Анонимділік:** Қатысушылардың жеке жазбалары, жеке хаттары (чаттары), күнделіктері мен дербес мәліметтері әкімшілікке және үшінші тұлғаларға ешқашан көрсетілмейді.
- **Псевдонимдер жүйесі:** Психолог кабинетінде қатысушылар тек ойдан шығарылған анонимді бүркеншік аттармен («Аққу-42», «Қыран-77» т.б.) көрінеді.
- **Ірі топтарға арналған жиынтық статистика:** Деанонимизация қаупін болдырмау үшін статистика тек кемінде **15 адамнан** тұратын топтар үшін ғана есептеледі. Шағын топтар үшін баллдар автоматты түрде жасырылады.
- **Демо-режим:** Тестілеу кезеңінде барлық көрсеткіштер мен өтінімдер тек ойдан шығарылған жиынтық деректер ретінде белгіленген («Демо-деректер», «Демо-режим. Нақты қабылдауға жазылу жүргізілмейді»).

## 🚀 Қызметкерлер кабинеттері (Staff Features)

### 1. Әкімшілік кабинеті (Admin Dashboard)
- **Файл:** `src/features/staff/AdminDashboard.tsx`
- **Маршрут:** `/admin/dashboard`
- **Мүмкіндіктері:**
  - Толық қазақ тіліндегі интерфейс
  - Браузер вкладкасы: `DOPAMINE — Әкімшілік кабинеті`
  - Кезеңді таңдау сүзгісі (7 күн, 14 күн, 30 күн)
  - 1-ден 5-ке дейінгі шкаладағы орташа көңіл-күй динамикасының SVG-графигі
  - Таңдалған периодтағы бірегей қатысушылар саны
  - Ірі топтар бойынша мониторинг және құпиялылық шегін бақылау

### 2. Психолог кабинеті (Psychologist Dashboard)
- **Файл:** `src/features/staff/PsychologistDashboard.tsx`
- **Маршрут:** `/psychologist/dashboard`
- **Мүмкіндіктері:**
  - Тек тағайындалған демо-өтінімдер тізімі
  - Әр өтінім үшін: бүркеншік ат (псевдоним), кездесу күні мен уақыты, өтінім күйі, сессияны жазуға келісім мәртебесі
  - Динамикалық түймелер: «Қабылдау» және «Бас тарту» (басқан соң мәртебе бірден жаңарады)
  - Сүзгі қойындылары және өтінімдер болмаған жағдайда «Әзірге өтінім жоқ» хабарламасы
  - **Рұқсат шектеуі (RBAC):** Әкімшілікке (Admin) бұл бөлімге тікелей сілтеме арқылы да кіру шектелген

## 💻 Жобаға қосу (Интеграция)

Негізгі жүйеге кабинеттерді маршрутизатор арқылы қосу үлгісі:

```tsx
import AdminDashboard from '@/features/staff/AdminDashboard';
import PsychologistDashboard from '@/features/staff/PsychologistDashboard';

// Маршрутизаторға қосу (мысалы, React Router):
<Route path="/admin/dashboard" element={<AdminDashboard />} />
<Route 
  path="/psychologist/dashboard" 
  element={<PsychologistDashboard currentRole="psychologist" />} 
/>
```

# Dopamine AI

Демо-проект на базе **Supabase (PostgreSQL)** с моделью ролей (`student`, `pupil`, `psychologist`, `admin`), явным согласием на запись и расшаривание записей настроения, а также анонимизированной агрегированной статистикой по учебным заведениям.

> **Важно:** Скрипты схемы и демо-данных предназначены **только для демо-проекта** с вымышленными данными. История чатов не хранится.

## Учебные заведения (Кызылорда)
- Университеты (`university`): `korkyt` — Қорқыт Ата атындағы Қызылорда университеті (демо), `bolashak` — Болашақ университеті (демо)
- Школы (`school`): `school264` — №264 мектеп (Қызылорда, демо), `school278` — №278 мектеп (Қызылорда, демо), `school2` — №2 мектеп (Қызылорда, демо), `school101` — №101 мектеп (Қызылорда, демо)

## Порядок запуска SQL в Supabase SQL Editor
1. `sql/001_dopamine_schema.sql`
2. `sql/002_dopamine_seed_demo.sql`
3. `sql/003_dopamine_verify.sql` для проверки сидов и агрегатов; `sql/004_dopamine_test_booking_and_mood.sql` для сценария записи, согласия и отзыва (все изменения откатываются в конце)
4. `sql/001_rollback.sql` (для полного отката)

## Переменные окружения
- Фронтенд: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`
- Бэкенд (`server/`): `PORT`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` (никогда не выкладывать реальные ключи и `.env` в GitHub)
